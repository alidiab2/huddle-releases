# Huddle — Android releases

Storybook party games for 2–8 phones on the same Wi-Fi.

This repository only holds **Android release builds** (APK files). The app's source code is not here.

## Install

1. Open the [latest release](../../releases/latest) on your Android phone and download `Huddle.apk`.
2. Open it and allow installing from your browser/files app if Android asks.

After that, Huddle checks for new versions when it starts and offers **Update now**.

## For the app

`latest.json` describes the newest release; the app reads it to know when an update is available.
Every APK here is signed with the same private release key, so Android only accepts updates made by us.
